# Droppable Gods
Adds Artemis, Athena, Dionysus and Hades to the god pool, allowing them to spawn as a normal Olympian god would.

To progress their respective stories, the primary way is still to find their encounters, however you can still give gifts to their boons to progress relationships (except for Hades).

### Dev
Included in the source code, there is a blender file, which is the file used to create the dropped icon for Hades.<br>
In order to add a trait to Artemis/Athena/Dionysus/Hades, please refer to the [dev](https://github.com/excellent-ae/zannc-Droppable_Gods/tree/main/dev) folder, which shows what is needed to add a boon to the God Pool - and allow it to be used along-side this mod.<br><br>

>For a full working example of multiple boons being added, refer to my [other mod, Practical Gods](https://github.com/excellent-ae/zannc-Practical_Gods), which was made to work with this mod specifically.
